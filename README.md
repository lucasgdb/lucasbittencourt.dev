# lucasbittencourt.dev

This is a porfolio site complete with a blog. Includes:

- MDX and Markdown support
- Optimized for SEO and AI discoverability (canonical URLs, sitemap, robots.txt, JSON-LD, llms.txt). See [docs/SEO.md](docs/SEO.md)
- RSS Feed
- Dynamic OG images
- Syntax highlighting
- Tailwind v4
- Vercel Speed Insights / Web Analytics
- Geist font

## Scripts

- `pnpm dev`: development server
- `pnpm build`: production build
- `pnpm test`: SEO tests (sitemap, robots.txt, JSON-LD, RSS, llms.txt)
- `pnpm typecheck`: TypeScript check
